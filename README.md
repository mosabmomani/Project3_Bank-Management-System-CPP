# C++ Bank Management System

A comprehensive console-based bank and client management application built in C++ that handles persistent data storage, client record management, and financial transactions.

> **Note:** This project is one of my earlier portfolio projects developed during my self-taught C++ and programming learning journey.

## Features
- **Client Management:** Add new clients, update client information, delete records, find clients by account number, and display a complete list of all clients.
- **Financial Transactions:** Perform secure deposits, withdraw funds with built-in balance verification to prevent overdrafts, and view total bank balances across all accounts.
- **File Persistence:** Automatically saves, updates, and loads client records using local text files (`clientdata.txt`) with custom delimiters.
- **Interactive Console Menus:** Clean, structured menu navigation with robust input validation.

## Getting Started

### Prerequisites
Make sure you have a C++ compiler installed (such as GCC, MinGW, or MSVC).

### Compilation and Execution
Open your terminal or command prompt in the project directory and run the following commands:
